Functions and the Apply Family in R

Functions and Apply Family Quiz

Test your knowledge of custom functions, lexical scoping, and the powerful apply family in Base R.

Question 1: Defining a Function

What is the correct syntax for creating a custom function in R?

In R, functions are objects. You define them using the function() keyword and assign them to a variable name using the standard assignment operator (<-).

Question 2: Default Arguments

How do you specify a default value of 10 for an argument y in a function?

Default arguments are set using the = operator directly inside the function's parameter list. If the user does not provide y, it will automatically default to 10.

Question 3: Return Values

If a function does not have an explicit return() statement, what does it output?

By default, R functions automatically return the value of the last evaluated expression in the function body. Explicit return() statements are only strictly required if you want to exit the function early.

Question 4: The ... Argument

What is the purpose of the dot-dot-dot (...) argument in an R function?

The ... argument captures any additional arguments passed by the user and can easily pass them along to another function (for example, passing graphing parameters like col or pch down to the plot() function).

Question 5: Anonymous Functions

Which of the following is an example of an anonymous function (a function without a name)?

Anonymous functions are defined on-the-fly directly inside another function call (like lapply). Because they are not assigned to a variable name, they are "anonymous."

Question 6: Checking for Arguments

Which function checks if a user provided a specific argument when calling your function?

The missing(x) function returns TRUE if the argument x was not provided in the function call, which is useful for setting up conditional logic based on what the user supplied.

Question 7: Returning Multiple Values

How can you return multiple distinct values (like a mean and a standard deviation) from a single custom function?

An R function can only return a single object. To return multiple pieces of information, you must bundle them together into a single object, typically a list or a vector.

Question 8: The apply() Function Margins

In the function apply(my_matrix, MARGIN = 1, FUN = sum), what does MARGIN = 1 indicate?

In apply(), MARGIN = 1 applies the function row-by-row, while MARGIN = 2 applies it column-by-column.

Question 9: Output of lapply()

What data structure does lapply() always return?

The "l" in lapply stands for "list." No matter what you pass into it, lapply() will always return a list of the same length as the input object.

Question 10: sapply() vs lapply()

What is the primary difference between sapply() and lapply()?

The "s" in sapply stands for "simplify." It runs lapply() under the hood but then tries to squeeze the resulting list into a simpler format (like a vector) if all the returned elements are the same length.

Question 11: Safest Apply Function

Which function is considered the safest alternative to sapply() for programming because it requires you to explicitly specify the expected output type?

vapply() requires a FUN.VALUE argument where you dictate what type of output is expected (e.g., numeric(1)). If the function generates something unexpected, it throws a strict error, making it safer for scripts than sapply().

Question 12: Grouped Operations

Which apply function is best used to apply a function over subsets of a vector, split by a categorical grouping variable (factor)?

tapply() computes a measure (like mean or sum) for each distinct group or category provided in its INDEX argument.

Question 13: lapply() on a Data Frame

If you run lapply(my_dataframe, is.numeric), what exactly is the function applied to?

A data frame in R is fundamentally just a list of columns. Because lapply() iterates over the elements of a list, running it on a data frame applies the function column-by-column.

Question 14: apply() on a Data Frame Warning

Why can using apply(my_dataframe, 1, sum) be dangerous or cause unexpected results if your data frame has mixed data types?

apply() is designed for arrays and matrices. If you pass a data frame containing both numbers and text, R coerces the whole matrix into characters to unify the type, meaning arithmetic functions like sum will fail.

Question 15: Multivariate Apply

If you want to apply a function in parallel over multiple lists or vectors (e.g., summing the 1st elements together, then the 2nd elements together), which function should you use?

mapply() stands for "multivariate apply." It takes multiple vectors/lists as arguments and applies a function to their corresponding elements simultaneously.

Question 16: Replicating Simulations

Which function is a convenient wrapper for sapply() that is used specifically to evaluate an expression repeatedly, making it ideal for Monte Carlo simulations?

replicate(n, expr) evaluates a given expression n times and simplifies the output. It is commonly used for repeating simulations or generating random datasets.

Question 17: Lexical Scoping

If a variable is called inside a function but is not defined within the function's arguments or its body, where will R look for it first?

R uses lexical scoping. It first searches inside the function. If it doesn't find the variable, it looks in the environment where the function was created (which is usually, but not always, the global environment).

Question 18: sapply() Edge Case

If you use sapply() on a list, but the function returns vectors of varying lengths for each element, what does sapply() output?

If the lengths of the outputs differ, sapply() cannot simplify them into a neat rectangular matrix or vector. When simplification fails, it gracefully falls back to returning a list (exactly like lapply).

Question 19: The FUN Argument

When passing a function into apply(), how should the function name be written?

You pass the function object itself by name, without parentheses. Adding parentheses (like mean()) evaluates the function immediately rather than passing it to apply().

Question 20: Executing a Function Call from a List

If you have a function and a list of arguments, which function lets you construct and execute the function call? (e.g., running rbind() on a list of data frames).

do.call(what, args) takes a function name (what) and a list of arguments (args), and executes the function as if the list elements were passed individually. E.g., do.call(rbind, list_of_dfs) row-binds a list of data frames together.
