Probability and Distributions in R

Welcome to the Probability Quiz!

Test your knowledge of random distributions, probability functions, and simulations in Base R. Select the correct answer for each question below.

Question 1: Reproducibility in Probability

Which function is used to ensure that a sequence of random numbers generated in R can be exactly reproduced by another user?

Using set.seed(123) (or any integer) forces R's random number generator to start at the exact same sequence, making simulations fully reproducible.

Question 2: The Prefix Convention

In R, probability distributions use a standard set of prefixes (d, p, q, r). Which prefix is used to calculate the Cumulative Distribution Function (CDF)?

The p prefix stands for "probability" and calculates the CDF (the probability that a random variable is less than or equal to a value). d is for density, q is for quantile, and r is for random generation.

Question 3: Simulating a Die Roll

How would you simulate rolling a fair six-sided die 10 times in R?

Because a die can land on the same number multiple times, you must sample from the numbers 1 to 6 with replacement (replace = TRUE).

Question 4: Normal Distribution Density

Which function returns the height of the probability density function (PDF) for a normal distribution at a specific value x?

The d prefix stands for "density", which evaluates the PDF curve at the given coordinate.

Question 5: Generating Normal Random Variables

What does the code rnorm(5, mean = 10, sd = 2) do?

The rnorm() function takes the number of observations (n), the mean, and the standard deviation (sd) as its primary arguments.

Question 6: Uniform Distribution

Which command generates a single random number uniformly distributed between 0 and 1?

runif() stands for "random uniform." It generates a continuous decimal value equally likely to fall anywhere between the min and max parameters.

Question 7: Exact Binomial Probability

How do you calculate the exact probability of getting exactly 3 heads in 10 flips of a fair coin?

For discrete distributions like the binomial, the density function (d prefix) calculates the exact probability of a specific outcome \(P(X = x)\).

Question 8: Cumulative Binomial Probability

Which function calculates the probability of getting 3 or fewer heads in 10 flips of a fair coin?

The p prefix (CDF) sums up the probabilities of getting 0, 1, 2, and 3 heads \(P(X \le 3)\).

Question 9: Poisson Distribution

If a call center receives an average of 5 calls per hour, which function finds the probability of receiving exactly 7 calls in a specific hour?

The dpois() function evaluates the probability mass for the Poisson distribution. The lambda argument represents the known average rate.

Question 10: Combinatorics

Which R function calculates the number of combinations (e.g., "10 choose 3")?

The choose(n, k) function is a built-in base R function that computes the binomial coefficient, avoiding manual factorial arithmetic.

Question 11: Weighted Sampling

How do you draw a single item from the vector c('A', 'B'), where 'A' has a 70% probability of being chosen and 'B' has a 30% probability?

The sample() function accepts a prob argument where you can pass a vector of custom probabilities corresponding to each item you are sampling.

Question 12: Finding Quantiles

Which function finds the Z-score corresponding to the 95th percentile of the standard normal distribution?

The q prefix stands for "quantile." It is the inverse of the CDF. If you give it a probability (0.95), it returns the threshold value (Z-score) below which that percentage of the data lies.

Question 13: Upper Tail Probabilities

By default, pnorm(1.96) calculates the lower tail \(P(X \le 1.96)\). How do you calculate the upper tail probability \(P(X > 1.96)\) using the same function?

Setting the lower.tail argument to FALSE is the standard way to calculate upper tail probabilities in R, which is mathematically equivalent to 1 - pnorm(1.96).

Question 14: The Exponential Distribution

What does rexp(10, rate = 0.2) generate?

The r prefix generates random sequences, and exp references the exponential distribution, which models the time between events using the rate parameter.

Question 15: Factorials in Math

To calculate \(5!\) (5 factorial), which R code should you use?

R has a dedicated factorial() function. Using the literal exclamation mark (5!) will result in a syntax error because ! is used as the logical "NOT" operator in R.

Question 16: Empirical Probabilities

If x <- runif(100), what does mean(x < 0.2) approximately evaluate to?

When you take the mean of a logical statement (like x < 0.2), R treats TRUE as 1 and FALSE as 0. Therefore, the average equals the proportion of times the condition was met.

Question 17: Default Sampling Behavior

What happens if you run sample(1:50, 5)?

By default, the sample() function always operates without replacement (replace = FALSE). You must explicitly change this if you want duplicate draws.

Question 18: Student's t-Distribution

Which function finds the cumulative probability \(P(T \le 2.1)\) for a t-distribution with 15 degrees of freedom?

The p prefix is used for the cumulative probability, and t represents the t-distribution. The degrees of freedom are set using the df argument.

Question 19: Chi-Squared Simulation

How do you generate 20 random observations from a Chi-squared distribution with 4 degrees of freedom?

The function name for the Chi-squared distribution in R is chisq. Adding the r prefix allows you to generate random values from it.

Question 20: Calculating Empirical Probability

You simulate 1000 coin flips with flips <- sample(c('H', 'T'), 1000, replace = TRUE). Which of the following correctly calculates the empirical probability of getting heads ('H')?

Summing the true statements and dividing by the total sum(x) / length(x) is mathematically identical to just calculating the average of the true statements mean(x). Both are completely valid ways to calculate probability in simulations.
