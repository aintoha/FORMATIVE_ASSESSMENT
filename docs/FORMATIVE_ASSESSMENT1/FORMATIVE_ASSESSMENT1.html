Part 1: Theory Questions

Question 1: R Assignment Operators

Which of the following statements correctly describes the primary ways to assign variables in R?

    1. Variables can only be assigned using the = operator.
    1. Variables can only be assigned using the <- operator.
    1. Variables can be assigned using either the <- or the = operator.
    1. Variables are assigned using -> for left-to-right assignment only.

There are two primary ways to assign variables in R, using <- or =. While -> exists for right-to-left assignment, <- and = are the standard primary assignment methods.

Question 2: Understanding R Objects

What is the abstract term for anything that can be assigned to a variable in R, and which of these is not listed as a general object type in the primary enumeration?

    1. An expression; functions are not listed.
    1. A function; integers are not listed.
    1. An object; matrices are not listed as a general type under core object types.
    1. A variable; vectors are not listed.

“Object” is the abstract term for anything assigned to a variable. Core enumerated object types include integers, vectors, and lists. While matrices are important data structures, they are built on vectors rather than listed as a standalone core type initially.

Question 3: Data Types in R

Which of the following combinations correctly lists four main types of data in R and their corresponding examples?

    1. Numerical (1000L), Character (TRUE), Integer (“Table”), Boolean (1)
    1. Character (“Table”), Integer (1000L), Boolean (TRUE), Numerical (1)
    1. Numerical (“Table”), Character (1), Integer (TRUE), Boolean (1000L)
    1. Integer (1), Boolean (“Table”), Numerical (TRUE), Character (1000L)

In R: * "Table" is a Character string. * 1000L (with the L suffix) is an Integer. * TRUE is a Boolean / Logical. * 1 is Numeric.

Question 4: Characteristics of Vectors

Which statement accurately describes a crucial characteristic of vectors in R, particularly concerning arithmetic operations?

    1. Vectors must always contain data of mixed types.
    1. For calculations with vectors to be straightforward, they should generally be of the same length.
    1. Character vectors use acute accent keys for text strings.
    1. Data vectors are exclusively used for integers.

Vector calculations operate element-by-element, so vectors should generally be of equal length to avoid unexpected recycling behavior.

Question 5: Functions and Arguments

In an R function call like log(x), what is the difference between x when it’s provided in the call versus its definition within the function’s structure?

    1. x in the call is a ‘formal argument’, while in the function definition it’s an ‘actual argument’.
    1. Both are always ‘formal arguments’.
    1. x as provided in log(x) is an ‘actual argument’, connected to a ‘formal argument’ defined within the function.
    1. x is neither an actual nor formal argument; it’s always an ‘object’.
  • Actual arguments are the specific values/variables passed during a function call.
  • Formal arguments are the parameters declared in the function’s definition.

Question 6: The Purpose of Factors

Why are ‘factors’ considered useful in R, particularly in statistical data analysis?

    1. They allow vectors to contain mixed data types.
    1. They are primarily used for mathematical matrix operations.
    1. They represent categorical variables, which is useful for indicating subdivisions of data and have a set of levels.
    1. They are a more efficient way to store numerical sequences.

Factors store categorical variables (like experimental groups or levels of treatment) and track predefined levels.

Question 7: Differentiating Lists and Vectors

What is the fundamental difference between a ‘list’ and a ‘vector’ in R regarding the types of objects they can contain?

    1. Vectors can hold objects of different types, while lists can only hold objects of the same type.
    1. Lists can hold collections of objects of different types, whereas a vector must contain elements of the same type.
    1. Both lists and vectors can hold any type of object without restriction.
    1. Lists are only for numeric data, and vectors are for character data.

Atomic vectors require all elements to be of the exact same data type (homogenous). Lists are generic vectors that can store elements of varying types and shapes (heterogeneous).

Question 8: Data Frames Structure

What is a ‘data frame’ in R, and what is its crucial characteristic regarding the length of its constituent components?

    1. A data frame is a single vector of mixed data types; its components can have varying lengths.
    1. A data frame is a matrix that can only store numeric values.
    1. A data frame is a list of vectors and/or factors of the same length, where data in the same position come from the same experimental unit.
    1. A data frame is an arbitrary collection of R objects without any length constraints.

A data frame is structured like a table where each column is a vector or factor. All columns must have identical lengths (rows) for the data frame to be valid.

Question 9: Printing Output: print() vs. cat()

When displaying a character vector in R, what is the primary difference between using print() and cat()?

    1. print() displays only the first element, while cat() displays all elements.
    1. cat() always adds a newline character after each element, while print() does not.
    1. print() includes quotation marks around character strings, whereas cat() displays them without quotation marks.
    1. print() is used for numeric data, and cat() is for character data.

print() outputs formal string representations including quotes (e.g., "John"), whereas cat() concatenates and prints raw unquoted text (e.g., John).

Question 10: Handling Missing Values (NA)

If you perform an arithmetic operation in R like 1 + NA, what will be the typical result, and why?

    1. The result will be 1, because NA is treated as 0 in arithmetic operations.
    1. The operation will produce an error, as NA cannot be used in arithmetic.
    1. The result will be NA, because R treats NA as missing information and does not assume it is 0.
    1. The result will be NaN (Not a Number), indicating an undefined operation.

R propagates NA values throughout calculations because operating on unknown data yields an unknown (NA) result.

Question 16: Factor Application

Given rating_values <- c(1, 0, 2, 1, 3, 0), you create a factor customer_rating from it with levels "Poor", "Fair", "Good", "Excellent" representing 0, 1, 2, and 3 respectively. What would as.numeric(customer_rating) return?

    1. c(“Fair”, “Poor”, “Good”, “Fair”, “Excellent”, “Poor”)
    1. c(0, 1, 2, 1, 3, 0)
    1. c(“Poor”, “Fair”, “Good”, “Excellent”)
    1. c(2, 1, 3, 2, 4, 1)

Factors store levels internally as integers starting at 1. Since "Poor" (0) is the first level, it gets coded as 1, "Fair" (1) becomes 2, "Good" (2) becomes 3, and "Excellent" (3) becomes 4.
